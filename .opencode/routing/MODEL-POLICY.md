# 9Router Model Policy

9router/combo-free
- cheapest tier
- low-risk, read-only work
- never final authority

9router/combo-gemini
- analysis and QA-heavy workloads
- broad context and test evidence

9router/combo-sonnet
- orchestration
- standard implementation
- automation engineering

9router/combo-opus
- architecture
- complex coding
- debugging
- security
- performance
- independent review
- release gate

Do not route based on model prestige alone. Route based on risk and required reasoning.
